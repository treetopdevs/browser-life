1. **P1 — Test 9 cannot construct its CPU simulator.** The [plan’s RPS fixture](./docs/visualization-gaps-2026-11-14/slab-viewer/PLAN.md:115) sets PARAM1’s type and mask bytes. [`RefSim3` validates its input](./packages/sim-ref/src/step3d.ts:159), and [slab validation rejects those bytes](./packages/schema/src/world.ts:192). An in-memory invocation confirmed: `invalid state: lineage 0:3 at cell 0 has nonzero reserved genome bytes`. **Fix:** use a valid stock ecology fixture for the CPU picture pin; test RPS through the imported GPU spike. Preserve the validators and pins.

2. **P1 — The mandatory reproduction gate has the wrong expected value.** [Test 23](./docs/visualization-gaps-2026-11-14/slab-viewer/PLAN.md:135) expects 0.5426 at step 5,000. The [actual TSV row](./experiments/3d-slab/m4-results.tsv:92) starts `0.0419 0.5426 1.0000`: those correspond to steps 5,000, 10,000 and 15,000 because [calibration samples every 5,000 steps](./experiments/3d-slab/m4-calibrate.ts:45). The operating-point description is consequently wrong too. **Fix:** expect 0.0419 at exactly step 5,000, using seed 101, the full recorded config and the lineage-based living predicate. Compare rounded fractions derived from raw counts. Also remove the [claim that test 23 checks the 50,000-step picture](./docs/visualization-gaps-2026-11-14/slab-viewer/PLAN.md:18); it does not.

3. **P1 — The documented simulator import path resolves outside the intended directory.** From the proposed `apps/lab/src/slab/worlds.ts`, [`../../../experiments/...`](./docs/visualization-gaps-2026-11-14/slab-viewer/PLAN.md:102) resolves to `apps/experiments/...`, which does not exist. **Fix:** use `../../../../experiments/3d-rps/gate0-spike/...` and retain a build check importing the actual final module.

4. **P2 — A generation counter does not enforce one simulator at a time.** The [switch procedure](./docs/visualization-gaps-2026-11-14/slab-viewer/PLAN.md:72) handles late readbacks but leaves overlapping asynchronous creates unspecified. Two rapid changes can start two creations before either becomes the current simulator. [`GpuSim3.create`](./experiments/3d-rps/gate0-spike/gpu-sim3-rps.ts:146) awaits pipeline creation. **Fix:** serialize creation, advancement, snapshots and hand-over; destroy superseded creation results. Define device ownership too: [`sim.destroy()` destroys buffers, not its GPUDevice](./packages/sim-gpu/src/gpu-sim3.ts:448). Test rapid consecutive changes during creation and hand-over.

5. **P2 — Test 24 can pass with an incorrect hand-over.** Its [counter/status assertions](./docs/visualization-gaps-2026-11-14/slab-viewer/PLAN.md:136) do not prove that cells, genomes and ledgers survive rebuilding, or that the kill actually becomes active. Batching by 100 also does not enforce the boundary after a manual Step: starting at step 1 and advancing 400 repeatedly straddles 6,000. The [real harness reads and preserves the whole state](./experiments/3d-rps/lib/kernel-job.ts:401). **Fix:** split advancement exactly at 6,000, compare state before and immediately after rebuilding, and verify subsequent output against a short direct spike run. Include a boundary-straddling case.

6. **P2 — The picture and census checks lack an independent GPU oracle.** [Test 9](./docs/visualization-gaps-2026-11-14/slab-viewer/PLAN.md:115) checks founding offsets rather than actual GPU readback; [test 20](./docs/visualization-gaps-2026-11-14/slab-viewer/PLAN.md:132) compares two outputs that could share the same indexing error. Duplicate or reversed layers can preserve totals. The majority projection cannot recover the slab census at all. **Fix:** upload an asymmetric fixture with distinct markers across layers, obtain a real `readSnapshot`, and compare exact tile coordinates and counts independently. Pause at one snapshot and count each layer once, excluding the projection.

7. **P2 — The claimed lab-colour mirror omits required inputs and arithmetic.** [`lineagePixel(hi, lo, B, P, unit)`](./docs/visualization-gaps-2026-11-14/slab-viewer/PLAN.md:64) cannot reproduce the [WGSL dead-cell colour](./packages/sim-gpu/src/renderer.ts:63), which depends on nutrient `A`. Literal JavaScript `hi * 0x9e3779b9` also differs from wrapping u32 multiplication for sufficiently large lineage IDs. **Fix:** reuse [`lineageRGB`](./packages/metrics/src/render.ts:9), pass `A` for the background branch, and add nutrient-varying dead cells and large IDs to test 5.

8. **P2 — Removing `dist/slab` leaves the private entry’s bundles published.** The [privacy correction](./docs/visualization-gaps-2026-11-14/slab-viewer/PLAN.md:38) treats the absence of `manualChunks` as eliminating chunk handling. Vite still emits entry JavaScript and CSS under `/assets/`; the [Dockerfile copies the remaining entire build](./Dockerfile.site:10), and [Caddy serves those assets](./deploy/Caddyfile:52). **Fix:** exclude the slab entry from production builds, or isolate and remove all private-only output. Test the final served artifact, including private bundle URLs. This also addresses the planning source’s [explicit chunk requirement](/Users/nicholas/develop/browser-life-viz-log/docs/visualization-gaps-2026-11-14/PLAN.md:30).

9. **P2 — G3b can succeed without exercising a fresh production build.** The [gate commands](./docs/visualization-gaps-2026-11-14/slab-viewer/PLAN.md:151) omit both `pnpm build` and `BL_REQUIRE_BUILD_CHECK=1`. [`public-not-found.spec.ts` explicitly permits skipping](./tests/e2e/public-not-found.spec.ts:37). The later [`site-build.test.ts` builds into a temporary directory and deletes it](./tools/test/site-build.test.ts:20), so it does not prepare `apps/lab/dist`. **Fix:** build the intended artifact first and require build checks. Serve that same artifact for privacy assertions.

10. **P2 — G4 does not establish byte identity against the starting revision.** Its [clean-status check](./docs/visualization-gaps-2026-11-14/slab-viewer/PLAN.md:153) compares against current HEAD; committed changes disappear from that check. The hash commands print values without asserting equality. **Fix:** compare protected paths against fixed base `7bb61be2014621b020968e6b60b8246b33990e04`, enforce an allowed-file diff, and make hash mismatches fail automatically. The current spike digest does match `761ea02a…140cc7`; preserve that baseline.

11. **P2 — Recorded-setting provenance contradicts the 128-size option.** The [size option promises Amendment 1 job IDs](./docs/visualization-gaps-2026-11-14/slab-viewer/PLAN.md:51), but [test 11 permits only Amendment 2 or M4 IDs](./docs/visualization-gaps-2026-11-14/slab-viewer/PLAN.md:119). Include Amendment 1 explicitly.

12. **P2 — The plan drops a required source gate without establishing a baseline.** The [source requires `pnpm test`](/Users/nicholas/develop/browser-life-viz-log/docs/visualization-gaps-2026-11-14/PLAN.md:32); the [slice explicitly removes it](./docs/visualization-gaps-2026-11-14/slab-viewer/PLAN.md:163). 13. **P2 — Two recorded-outcome explanations are false.** The [“most life” claim of 0.998](./docs/visualization-gaps-2026-11-14/slab-viewer/PLAN.md:46) is contradicted by [removal and control rows reaching 1](./experiments/3d-rps/GATE0-EXPLORATION-2.md:71). 14. **P3 — The UI checks do not substantiate all promised accessibility and explanation claims.** [String presence and length](./docs/visualization-gaps-2026-11-14/slab-viewer/PLAN.md:122) do not establish that choices explain why someone would pick them.
