## Rules fixed before the walk

- **works**: loads, no console error, the surface's main action visibly completes. **partly**: loads but a named action fails or needs an unlisted step, or the console logs an error. **broken**: does not load or crashes.
- A 200 alone is never works for a GPU page. `/selftest.html` is works only with a non-empty result list, every case ok and `window.__golden.error` unset.
- A shot of an error page is evidence of broken. Console errors are copied into `evidence/` as recorded.
- Four status axes on the page: implemented, locally verified (these verdicts), data available, deployed or externally verified (none: nothing here touched a live host).
