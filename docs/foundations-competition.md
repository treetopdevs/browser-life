# Equal-frequency genotype-only time-shift feasibility assay

`tools/foundation-competition.ts` creates an authenticated CPU-only plan by default. It needs five complete, observer-compatible M4 `gradient-m3/treatment` replay caches for seeds 1–5, their original source bundles, five frozen extraction catalogs, and one frozen extraction rule. Input JSON has `format: 1`, `rule` as an absolute path, and `sources` as an array of five `{source, cache, catalog}` absolute-path triples ordered by seed. An output directory is reserved create-new; existing artifacts are not resumed or overwritten. The runner rechecks original source files, cached checkpoint content and hashes, catalog contents, rule, and relevant code before a device request and after any execution. A failure retains a diagnostic artifact.

```text
deno run -A tools/foundation-competition.ts \
  --inputs /absolute/path/to/five-sources.json \
  --out /absolute/path/to/new-competition-plan
```

This is a **small genotype-only screen**, not an intact-organism fitness assay. At each source's early (100,000) and late (900,000) checkpoint, the plan records **every** component selected by the previously frozen catalog rule, the full component denominator, and selected/excluded counts by stratum. The number selected can vary by source and epoch. It ranks all selected components by SHA-256 of the rule digest, source run ID, epoch, and component index, and fixes rank zero as the donor. A selected donor that fails packet or ancestry validation stops the plan; no next-ranked or pilot-persistent substitute is used. A valid catalog with zero selected components records that source epoch as unavailable. Its dependent run rows remain in the fixed denominator as `not-run-unavailable` and request no GPU work. The middle checkpoint is authenticated and its catalog recomputed but does not supply a donor. Each chosen lineage is joined separately through the complete original mutation edge log to its actual initialized founder instance and M3 founder-set genome index. A source can contain more than one surviving founder origin.

Every inoculum uses one fixed, seeded evaluator-disc physical template (radius 10, mean biomass 64, energy 128). The template's positive-biomass cells are copied unchanged; only genotype words 2–43 are replaced by the selected early, late, or own-founder genome. The plan records its packet hash, state hash, cell count and exact inventory; each run stores the full transplant import/export audit. This holds starting morphology, biomass, energy and MOT fixed while deliberately removing evolved morphology and carried chemistry. All assay worlds use one 256×256 tile, mutation disabled, uniform light base 40/amplitude 160, no seasonal amplitude, 3,000 steps and 100-step censuses. Twenty matched **solo** standardized-garden controls are ordered first: each world's early and late donor genotype and each donor's own ancestor founder genotype, four runs per world. The four controls from one world share a fresh assay seed and the exact physical template so the founder comparison does not silently substitute one world-level founder for another donor's ancestry. These are **single-genotype persistence and growth** comparisons, not direct founder-versus-descendant competition. Neither founder nor zero-controller behavior is presumed in advance.

Each solo run also captures a compact in-situ observer trace at all 30 scheduled censuses. Step 100 is the window baseline: IDs already present there have unknown pre-baseline age and are marked left-truncated. Later IDs carry their observer-inferred birth step and age. The trace retains every tracked component's mass, biomass, membrane fraction, rim/core membrane contrast, compartment flag, lineage purity, and within-member-cell A/C/E/S means; every saved birth, budding, fission, fusion and death row; overlap mixing even where no fusion row is emitted; and a census-label digest. Saved labels and event totals must agree with decoded physics and observer state at each step. The capture keeps rolling label maps to identify mixing, then discards them; exact per-component cell membership is not retained. A completed solo row cannot be reused in a later batch without all 30 joined censuses and no pending event rows. Partial traces remain diagnostics after an interruption. The manifest leaves lifecycle analysis null pending a separately reviewed garden-specific analysis, so the existing source-world analysis scope is not silently applied to a new setting. These trajectories can describe persistence, splits, fusion, morphology and censoring under matched garden conditions. They do not prove a transmitted life cycle or genetic heredity: physical partitioning, shared chemical pools, inferred tracker identities and left truncation remain unresolved without serial transfer or further controls.

The 50 competition runs use five environments per donor world: its own early and late chemical pools, one deterministic next-world foreign pool at each time, and nutrient-32 standardized garden. Each environment has two **reciprocal genotype-to-side assignments** using the same seed and the same complete physical initial state; early and late start at equal, positive biomass and energy. The discs are centered at `(108,128)` and `(148,128)` with radius 10. The 5-cycle foreign assignment records the full donor–environment graph. Foreign contrasts share histories through that graph and are descriptive; they are not five independent foreign replicates. Equal-frequency performance is the only competition regime here. Rare invasion, frequency dependence, resident-community challenges and a Red Queen claim require separate assays.

The historical pool is an **intervention**, not the unchanged source surroundings. It retains dissolved A and C and signal S at every site, retains E only at sites originally unbound (`B+P=0`), exports resident B/P and E from bound sites, clears all genomes, neutralizes MOT and resets the cumulative ledgers at step zero. E is carried with biomass in the simulator, so preserving all bound-site E would transplant much of the residents' energy without their cells. The manifest records before, exported and after inventories for all six resources, total matter and physical energy, as well as the exact source checkpoint and conditioned-state hashes. The common template then overwrites identical left/right patches. Both transplant audits show `after = before + import − export`; reciprocal starting cell words, total resources, ledgers and RNG seed must match exactly. These native-conditioned pools are **not** normalized to equal totals across source times or worlds. Their early/late chemistry and resource quantity are inseparable in this screen. A resource-normalized chemistry arm would require its own explicit balancing intervention and interpretation; silently topping up a depleted pool would erase the sampled condition.

At each census the assay records labelled early and late B, matter/energy residuals, mutation count, and minimum toroidal inter-lineage Chebyshev distance. Adjacency means distance at most 1. Overlapping kernel halos mean distance at most twice the *actual configured* kernel radius; this is an opportunity for local exposure, not proof of interaction. The 100-step cadence can miss transient encounters. Each reciprocal arm's sampled opportunity is reported separately; if either lacks halo overlap, the pair's no-advantage interpretation is exposure-limited. The primary descriptive contrast, when both genotypes survive, is `log((late B at 3000 / late B at 0) / (early B at 3000 / early B at 0))`. There is no extinction pseudocount: early-only, late-only and neither-survives outcomes are reported as separate survival patterns, and reciprocal mean log contrast is calculated only when both assignments have finite contrasts. This measures relative biomass growth at this starting frequency and in this template, not universal fitness or increasing complexity.

GPU execution requires `--execute --max-seconds N --max-runs K` with `0 < N ≤ 600`, `1 ≤ K ≤ 8`; no more than eight run positions are attempted in one create-new artifact. Runs are ordered with all 20 solo controls before the 50 competition arms. A later batch uses `--run-offset J --prior-manifests /path/one.json,/path/two.json` and verifies matching frozen plans plus completed, conserving evidence or the same predeclared unavailability for **every** earlier row, so it cannot skip available controls. A prior completed row is reusable only from a successful, within-cap batch that records actual device evidence and a **post-execution** source/cache/code revalidation. Time caps leave an incomplete-run label with observed censuses; technical or conservation failure stops the batch. The manifest records Deno/OS, the actual device adapter, whole elapsed time and overrun, and SHA-256 of selected assay, extractor, ancestry, replay, schema, runner and metrics files before and after; this is explicitly a selected-file scope, not a complete dependency closure. An intact-packet pilot informs how morphology may matter but does not validate these genotype swaps, choose their donors, or make these outcomes confirmatory. Five source histories are a feasibility sample; organisms and arms are nested, and the foreign cycle adds cross-world dependence.
