Decisions

D1 — Complete the next operational gap

Expose supported coordinator settings in Compose and provide an opt-in client-address path through Caddy. This makes documented configuration usable without inventing a new scientific feature.

D2 — Trust no upstream by default

Use an empty static proxy allowlist by default, strict right-to-left parsing of X-Forwarded-For, and replace the upstream header with the single resolved client address. Document explicit Traefik CIDRs, isolated coordinator networking, and separate live verification before enabling per-address join limits. Do not default to all private networks.

D3 — Preserve release defaults

Pass through only existing runtime settings: BL_TRUST_FORWARDED_FOR, BL_ISLAND_JOINS_PER_ADDRESS, BL_MAX_ISLANDS, BL_CORS_ORIGINS and BL_LEASE_MS. Blank values retain coordinator defaults. Garden scheduling stays off, garden routes stay private, coordinator has no published port.

D4 — Use the requested reviewer directly

agy lists Claude Sonnet 5.5 High but returns RESOURCE_EXHAUSTED; Cursor requires authentication. Direct Claude CLI returned modelUsage claude-sonnet-5-5 successfully with --effort high. Use direct Claude for planning, implementation and adversarial review, plus the repository-required read-only Codex Sol 6.1 High phase/precommit review.

D5 — Resolve the phase review findings

Sol plan review required replacing broad private-range guidance, checking both Compose modes and live-host isolation, exercising production-line Caddy, updating the existing test harness, proving budget separation, and documenting lease headroom. The local gate uses the official Caddy 2.10.2 binary; the Alpine container and actual host networks remain separate live checks. Local tests will verify configuration and forwarding; existing Phoenix limiter tests plus a local Caddy/Phoenix check will distinguish address delivery from budget behavior. BL_LEASE_MS is milliseconds, default ten minutes; operators must leave heartbeat and retry headroom.

D6 — Adversarial review repairs

Sonnet 5.5 High found no blockers. Added a preflight using the actual mounted Caddyfile and release image: malformed CIDRs prevent site startup, unlike stale but valid entries. Clarified space-separated lists. Tests now pin alternate headers as untrusted pass-through data while address selection uses only XFF. Added explicit untrusted-peer, mixed-family allowlist and invalid-CIDR checks. Conditional tool checks, live network attachments and the unrun Alpine image remain explicit limitations.

D7 — Repair full-suite fallout from graceful leave

The initial full suite exposed two old runner assertions that allowed only join/next and rejected the new cleanup DELETE. Updated both to require exactly POST join, POST next, authenticated DELETE leave; unsupported work must still fetch no state and submit no task. Their 92 tests pass. The existing leave smoke also lacked the required no-lock Deno shim for its coordinator; reused the shared helper and retained the smoke's behavior. Both reviewers then caught credential/query assertions inside a caught fetch; these now run after the rejected island run, outside cleanup, and the 92-test rerun passes. These are test-only repairs to the previously merged leave feature, with no new runner behavior.

D8 — Preserve the test contract during verification

The initial broad run had three stale leave checks and two unchanged CPU-heavy timeouts. Fix only the stale tests. Re-run with two workers while retaining test limits, physics, rules, hash pins and scientific registration unchanged. A focused conservation run passed. The final full run passed all 3,791 tests across 154 files; this completes the local verification gate.
