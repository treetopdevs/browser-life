---
name: code-review
description: Review the changes since a fixed point (commit, branch, tag, or merge-base) along two axes — Standards (does the code follow this repo's documented coding standards?) and Spec (does the code match what the originating issue/PRD asked for?). Runs both reviews in parallel sub-agents and reports them side by side. Use when the user wants to review a branch, a PR, work-in-progress changes, or asks to "review since X".
---

Two-axis review of the diff between `HEAD` and a fixed point the user supplies:

- **Standards** — does the code conform to this repo's documented coding standards?
- **Spec** — does the code faithfully implement the originating issue / PRD / spec?

Both axes run as **parallel sub-agents** so they don't pollute each other's context, then this skill aggregates their findings.

The issue tracker should have been provided to you — run `/setup-matt-pocock-skills` if `docs/agents/issue-tracker.md` is missing.

## Process

### 1. Pin the fixed point

Whatever the user said is the fixed point — a commit SHA, branch name, tag, `main`, `HEAD~5`, etc. If they didn't specify one, ask for it.

Capture the diff command once: `git diff <fixed-point>...HEAD` (three-dot, so the comparison is against the merge-base). Also note the list of commits via `git log <fixed-point>..HEAD --oneline`.

Before going further, confirm the fixed point resolves (`git rev-parse <fixed-point>`) and the diff is non-empty. A bad ref or empty diff should fail here — not inside two parallel sub-agents.

### 2. Identify the spec source

Look for the originating spec, in this order:

1. Issue references in the commit messages (`#123`, `Closes #45`, GitLab `!67`, etc.) — fetch via the workflow in `docs/agents/issue-tracker.md`.
2. A path the user passed as an argument.
3. A PRD/spec file under `docs/`, `specs/`, or `.scratch/` matching the branch name or feature.
4. If nothing is found, ask the user where the spec is. If they say there isn't one, the **Spec** sub-agent will skip and report "no spec available".

### 3. Identify the standards sources

Anything in the repo that documents how code should be written, such as `CODING_STANDARDS.md` or `CONTRIBUTING.md`.

On top of whatever the repo documents, the Standards axis always carries the **smell baseline** below — a fixed set of Fowler code smells (_Refactoring_, ch.3) that applies even when a repo documents nothing. Two rules bind it:

- **The repo overrides.** A documented repo standard always wins; where it endorses something the baseline would flag, suppress the smell.
- **Always a judgement call.** Each smell is a labelled heuristic ("possible Feature Envy"), never a hard violation — and, like any standard here, skip anything tooling already enforces.

Each smell reads *what it is* → *how to fix*; match it against the diff:

- **Mysterious Name** — a function, variable, or type whose name doesn't reveal what it does or holds. → rename it; if no honest name comes, the design's murky.
- **Duplicated Code** — the same logic shape appears in more than one hunk or file in the change. → extract the shared shape, call it from both.
- **Feature Envy** — a method that reaches into another object's data more than its own. → move the method onto the data it envies.
- **Data Clumps** — the same few fields or params keep travelling together (a type wanting to be born). → bundle them into one type, pass that.
- **Primitive Obsession** — a primitive or string standing in for a domain concept that deserves its own type. → give the concept its own small type.
- **Repeated Switches** — the same `switch`/`if`-cascade on the same type recurs across the change. → replace with polymorphism, or one map both sites share.
- **Shotgun Surgery** — one logical change forces scattered edits across many files in the diff. → gather what changes together into one module.
- **Divergent Change** — one file or module is edited for several unrelated reasons. → split so each module changes for one reason.
- **Speculative Generality** — abstraction, parameters, or hooks added for needs the spec doesn't have. → delete it; inline back until a real need shows.
- **Message Chains** — long `a.b().c().d()` navigation the caller shouldn't depend on. → hide the walk behind one method on the first object.
- **Middle Man** — a class or function that mostly just delegates onward. → cut it, call the real target direct.
- **Refused Bequest** — a subclass or implementer that ignores or overrides most of what it inherits. → drop the inheritance, use composition.

### 4. Spawn both sub-agents in parallel

Send a single message with two `Agent` tool calls. Use the `general-purpose` subagent for both.

**Standards sub-agent prompt** — include:

- The full diff command and commit list.
- The list of standards-source files you found in step 3, **plus the smell baseline from step 3** pasted in full — the sub-agent has no other access to it.
- The brief: "Report — per file/hunk where relevant — (a) every place the diff violates a documented standard: cite the standard (file + the rule); and (b) any baseline smell you spot: name it and quote the hunk. Distinguish hard violations from judgement calls — documented-standard breaches can be hard, but baseline smells are always judgement calls, and a documented repo standard overrides the baseline. Skip anything tooling enforces. Under 400 words."

**Spec sub-agent prompt** — include:

- The diff command and commit list.
- The path or fetched contents of the spec.
- The brief: "Report: (a) requirements the spec asked for that are missing or partial; (b) behaviour in the diff that wasn't asked for (scope creep); (c) requirements that look implemented but where the implementation looks wrong. Quote the spec line for each finding. Under 400 words."

If the spec is missing, skip the Spec sub-agent and note this in the final report.

### 5. Aggregate

Present the two reports under `## Standards` and `## Spec` headings, verbatim or lightly cleaned. Do **not** merge or rerank findings — the two axes are deliberately separate (see _Why two axes_).

End with a one-line summary: total findings per axis, and the worst issue _within each axis_ (if any). Don't pick a single winner across axes — that's the reranking the separation exists to prevent.

## Why two axes

A change can pass one axis and fail the other:

- Code that follows every standard but implements the wrong thing → **Standards pass, Spec fail.**
- Code that does exactly what the issue asked but breaks the project's conventions → **Spec pass, Standards fail.**

Reporting them separately stops one axis from masking the other.

    53	## 4. Decision rule
    54	
    55	Readouts R: `meanA` (patch mean per object), `sharedBound`, `reuseRatio`, `maxCopies`, `copyWeightedConstruction`. Declared directions as in `GRAMMAR.md` section 5.
    56	
    57	R **separates** `hier-12` from `random-dup-12` in a grid cell iff, over all `R x R` replicate pairs, R is ordered in its declared direction in every pair (accuracy exactly 1; ties are not separation). A grid cell is one of: spaced patches at 4-connectivity (primary), spaced at 8-connectivity, `seam-` patches at 4, `seam-` patches at 8. The primary cell additionally requires that each of `random-dup`, `random-dup-hi` and `random-dup-12` is ordered strictly worse than every `hier-12` replicate on R (otherwise: the duplicated random motif scores as strongly as the weakest hierarchy replicate). `random-field`, `hierarchy`, `hierarchy-mixed` and the crystals are reported descriptively.
    58	
    59	Verdicts per readout:
    60	
    61	- `not directional`: `meanA`, `maxCopies`. Reported, cannot separate.
    62	- `measurement-limited`: the eligible set is empty (`null`).
    63	- `fails to separate`: no grid cell separates (this includes a duplicated random motif scoring as strongly as the weakest `hier-12` replicate). The report states in those words that **no life-detection claim is made** from R.
    64	- `segmentation-dominated`: grid cells disagree. Published as a sensitivity failure; no boundary is changed to rescue the treatment.
    65	- `separates` in every cell: then compared with baselines. `adds value over simple baselines` iff the readout accuracy (1) exceeds the best baseline accuracy (both directions tried) on the same pairs; otherwise `separates, but not beyond baselines`.
    66	
    67	Sampling sensitivity applies to movies only; static verdicts carry `n/a` for sampling, never `stable`.
    68	
    69	Declared before running (so surprises are visible): the naive `copyWeightedConstruction` is expected to fail on the duplicated-motif classes (high `a`, many copies); `maxCopies` cannot separate at matched multiplicity; `reuseRatio` and `sharedBound` may separate; none of this is tunable after the fact. Passing the hand-built hierarchy shows the readout tracks that construction, not that nature does.

    75	      const lo = Math.min(ca, cb), hi = Math.max(ca, cb);
    76	      seen.add(lo * 4096 + hi);
    77	    }
    78	    c.splits = [...seen].sort((p, q) => p - q).map((v) => [Math.floor(v / 4096), v % 4096] as [number, number]);
    79	  }
    80	  return { cells: cells.slice(), n, classOf, classes, adj };

    83	/** Exact state identity: two bitsets over class indices, packed 16 bits per char. */
    84	function stateKey(nClasses: number, inS: Set<number>, todo: readonly number[]): string {
    85	  const words = (nClasses + 15) >> 4;
    86	  const w = new Uint16Array(2 * words);
    87	  for (const c of inS) w[c >> 4] |= 1 << (c & 15);
    88	  for (const c of todo) w[words + (c >> 4)] |= 1 << (c & 15);
    89	  return String.fromCharCode.apply(null, w as unknown as number[]);
    90	}

    92	interface Search { space: Space; target: number; free: Set<number>; budget: number; nodes: number; exhausted: boolean; chosen: Map<number, [number, number]> }

    94	function dfs(sr: Search, inS: Set<number>, todo: number[], cost: number, K: number, failed: Set<string>): boolean {
    95	  if (todo.length === 0) return true;
    96	  if (++sr.nodes > sr.budget) { sr.exhausted = true; return false; }
    97	  const key = stateKey(sr.space.classes.length, inS, todo);
    98	  if (failed.has(key)) return false;
    99	  // expand the largest pending class (ties: smallest class index)
   100	  let bi = 0;
   101	  for (let i = 1; i < todo.length; i++) {
   102	    const a = sr.space.classes[todo[i]], b = sr.space.classes[todo[bi]];
   103	    if (a.size > b.size || (a.size === b.size && todo[i] < todo[bi])) bi = i;
   104	  }
   105	  const c = todo[bi];
   106	  const rest = todo.filter((_, i) => i !== bi);
   107	  const cls = sr.space.classes;
   108	  const room = K - cost;
   109	  const opts: { pa: number; pb: number; add: number[] }[] = [];
   110	  for (let pass = 0; pass <= Math.min(2, room); pass++) {
   111	    for (const [pa, pb] of cls[c].splits) {
   112	      const na = cls[pa].size >= 2 && !sr.free.has(pa) && !inS.has(pa);
   113	      const nb = pb !== pa && cls[pb].size >= 2 && !sr.free.has(pb) && !inS.has(pb);
   114	      const cnt = (na ? 1 : 0) + (nb ? 1 : 0);
   115	      if (cnt !== pass) continue;
   116	      const add: number[] = [];
   117	      if (na) add.push(pa);
   118	      if (nb) add.push(pb);
   119	      opts.push({ pa, pb, add });
   120	    }
   121	  }
   122	  for (const { pa, pb, add } of opts) {
   123	    for (const p of add) inS.add(p);
   124	    sr.chosen.set(c, [pa, pb]);
   125	    if (dfs(sr, inS, rest.concat(add), cost + add.length, K, failed)) return true;
   126	    for (const p of add) inS.delete(p);
   127	    sr.chosen.delete(c);
   128	    if (sr.exhausted) return false;
   129	  }
   130	  failed.add(key);
   131	  return false;
   132	}

   134	function dagFrom(sp: Space, sr: Search, target: number): DagEntry[] {
   135	  // Entries in dependency order (parts before wholes). Each class is realised by its representative mask.
   136	  const order: number[] = [];
   137	  const mark = new Set<number>();
   138	  const visit = (c: number): void => {
   139	    if (mark.has(c) || sp.classes[c].size < 2 || sr.free.has(c)) return;
   140	    mark.add(c);
   141	    const [a, b] = sr.chosen.get(c)!;
   142	    visit(a); visit(b);
   143	    order.push(c);
   144	  };
   145	  visit(target);
   146	  return order.map((c) => {
   147	    const rep = sp.classes[c].rep;
   148	    const [pa, pb] = sr.chosen.get(c)!;
   149	    // find a concrete partition of rep realising the chosen class pair
   150	    let a = 0;
   151	    const low = lowBit(rep);
   152	    for (let s = (rep - 1) & rep; s > 0; s = (s - 1) & rep) {
   153	      if (!(s & low)) continue;
   154	      const ca = sp.classOf.get(s), cb = sp.classOf.get(rep ^ s);
   155	      if (ca === undefined || cb === undefined) continue;
   156	      if (Math.min(ca, cb) === Math.min(pa, pb) && Math.max(ca, cb) === Math.max(pa, pb)) { a = s; break; }
   157	    }
   158	    const toCells = (m: number) => sp.cells.filter((_, i) => m & (1 << i));
   159	    return { key: sp.classes[c].key, cells: toCells(rep), a: toCells(a), b: toCells(rep ^ a) };
   160	  });
   161	}

   165	/** Exact minimum, or `undefined` result status "bound" with `cost` unset when the budget runs out (callers fall back). */
   166	export function exactConstruction(cells: readonly number[], opt: ExactOptions): { cost: number; exact: boolean; nodes: number; dag: DagEntry[] } {
   167	  const n = cells.length;
   168	  if (n > 12) throw new Error("exact search is limited to 12 cells");
   169	  if (n <= 1) return { cost: 0, exact: true, nodes: 0, dag: [] };
   170	  const sp = buildSpace(cells, opt.conn, opt.group);
   171	  const target = sp.classOf.get((1 << n) - 1)!;
   172	  const freeIdx = new Set<number>();
   173	  if (opt.free) sp.classes.forEach((c, i) => { if (opt.free!.has(c.key)) freeIdx.add(i); });
   174	  const sr: Search = { space: sp, target, free: freeIdx, budget: opt.budget, nodes: 0, exhausted: false, chosen: new Map() };
   175	  if (freeIdx.has(target)) return { cost: 0, exact: true, nodes: 0, dag: [] };
   176	  for (let K = Math.min(log2ceil(n), n - 1); K <= n - 1; K++) {
   177	    sr.chosen.clear();
   178	    const inS = new Set<number>([target]);
   179	    if (dfs(sr, inS, [target], 1, K, new Set<string>())) return { cost: K, exact: true, nodes: sr.nodes, dag: dagFrom(sp, sr, target) };
   180	    if (sr.exhausted) return { cost: -1, exact: false, nodes: sr.nodes, dag: [] };
   181	  }
   182	  throw new Error("unreachable: the monomer chain always exists");
   183	}

   194	  return sr.exhausted ? null : ok;

    16	function bfsOrder(cells: readonly number[], conn: Conn, from: number): number[] {
    17	  const set = new Set(cells);
    18	  const seen = new Set<number>([from]);
    19	  const out = [from];
    20	  for (let i = 0; i < out.length; i++) {
    21	    const c = out[i];
    22	    for (const [dx, dy] of NEIGHBOURS[conn]) {
    23	      const x = cx(c) + dx, y = cy(c) + dy;
    24	      if (x < 0 || y < 0) continue;
    25	      const n = code(x, y);
    26	      if (set.has(n) && !seen.has(n)) { seen.add(n); out.push(n); }
    27	    }
    28	  }
    29	  return out;
    30	}

    33	export function chainDag(cells: readonly number[], conn: Conn): DagEntry[] {
    34	  const order = bfsOrder(cells, conn, cells[0]);

    38	    dag.push({ key: canonicalKey(cur), cells: cur.slice().sort((a, b) => a - b), a: order.slice(0, i - 1).sort((a, b) => a - b), b: [order[i - 1]] });

    43	interface Cand { a: number[]; b: number[]; ka: string; kb: string }
    44	
    45	function candidates(c: readonly number[], st: State, known: Map<string, number[]>, free: ReadonlySet<string>, conn: Conn): Cand[] {
    46	  const n = c.length;
    47	  const set = new Set(c);
    48	  const seenPair = new Set<string>();
    49	  const out: Cand[] = [];
    50	  const push = (a: number[], b: number[]): void => {
    51	    if (a.length === 0 || b.length === 0) return;
    52	    const ka = canonicalKey(a), kb = canonicalKey(b);
    53	    const pk = ka < kb ? ka + "|" + kb : kb + "|" + ka;
    54	    if (seenPair.has(pk)) return;
    55	    if (!isConnected(a, conn) || !isConnected(b, conn)) return;
    56	    seenPair.add(pk);
    57	    out.push({ a, b, ka, kb });
    58	  };
    59	  // copy-aware: place a known pattern inside c so that the remainder is connected
    60	  for (const [key, pat] of known) {
    61	    if (pat.length < 2 || pat.length >= n) continue;
    62	    const base = pat[0];
    63	    for (const anchor of c) {
    64	      const dx = cx(anchor) - cx(base), dy = cy(anchor) - cy(base);
    65	      let ok = true;
    66	      const placed: number[] = [];
    67	      for (const p of pat) {
    68	        const x = cx(p) + dx, y = cy(p) + dy;
    69	        if (x < 0 || y < 0) { ok = false; break; }
    70	        const q = code(x, y);
    71	        if (!set.has(q)) { ok = false; break; }
    72	        placed.push(q);
    73	      }
    74	      if (!ok) continue;
    75	      const ps = new Set(placed);
    76	      push(placed.sort((a, b) => a - b), c.filter((q) => !ps.has(q)));
    77	    }
    78	    void key;
    79	  }
    80	  // sweeps: prefixes of fixed orders
    81	  const orders: number[][] = [
    82	    c.slice(),
    83	    c.slice().sort((a, b) => cx(a) - cx(b) || cy(a) - cy(b)),
    84	    c.slice().reverse(),
    85	    c.slice().sort((a, b) => cx(b) - cx(a) || cy(b) - cy(a)),
    86	    bfsOrder(c, conn, c[0]),
    87	    bfsOrder(c, conn, c[n - 1]),
    88	  ];
    89	  const lens = n <= 16 ? Array.from({ length: n - 1 }, (_, i) => i + 1) : [1, n >> 1, (n + 1) >> 1, n - 1];
    90	  for (const ord of orders) for (const L of lens) {
    91	    const pre = new Set(ord.slice(0, L));
    92	    push(ord.slice(0, L).sort((a, b) => a - b), c.filter((q) => !pre.has(q)));
    93	  }
    94	  void st; void free;
    95	  return out;
    96	}

    98	export function boundConstruction(cells: readonly number[], opt: BoundOptions): BoundResult {
    99	  const n = cells.length;
   100	  if (n <= 1) return { cost: 0, nodes: 0, dag: [], fallback: false };
   101	  const free = opt.free ?? new Set<string>();
   102	  const tkey = canonicalKey(cells);
   103	  const chain = (nodes: number): BoundResult => ({ cost: n - 1, nodes, dag: chainDag(cells, opt.conn), fallback: true });
   104	  if (free.has(tkey)) return { cost: 0, nodes: 0, dag: [], fallback: false };
   105	  const init: State = { entries: new Map(), pending: new Map([[tkey, cells.slice()]]) };
   106	  let beam: State[] = [init];
   107	  let nodes = 0;
   108	  const freePatterns = new Map<string, number[]>();
   109	  for (const k of free) freePatterns.set(k, keyCells(k));
   110	  while (beam.length) {
   111	    if (beam[0].pending.size === 0) {
   112	      const dag = [...beam[0].entries.values()];
   113	      const ordered = orderDag(dag);
   114	      const cost = ordered.length;
   115	      if (cost <= n - 1 || free.size > 0) return { cost, nodes, dag: ordered, fallback: false };
   116	      return chain(nodes);
   117	    }
   118	    if (nodes > opt.nodeCap) return chain(nodes);
   119	    const next: State[] = [];
   120	    const seen = new Set<string>();
   121	    for (const s of beam) {
   122	      if (s.pending.size === 0) { const k = stateKey(s); if (!seen.has(k)) { seen.add(k); next.push(s); } continue; }
   123	      // expand the largest pending class (ties: smallest key)
   124	      let bk = "";
   125	      let bn = -1;
   126	      for (const [k, v] of s.pending) if (v.length > bn || (v.length === bn && k < bk)) { bk = k; bn = v.length; }
   127	      const cc = s.pending.get(bk)!;
   128	      const known = new Map<string, number[]>(freePatterns);
   129	      for (const [k, e] of s.entries) known.set(k, keyCells(k).length ? keyCells(k) : e.cells);
   130	      for (const [k] of s.pending) known.set(k, keyCells(k));
   131	      known.delete(bk);
   132	      const cands = candidates(cc, s, known, free, opt.conn);
   133	      const scored = cands.map((cd) => {
   134	        const fresh = new Set<string>();
   135	        for (const [k, p] of [[cd.ka, cd.a], [cd.kb, cd.b]] as const) if (p.length >= 2 && !s.entries.has(k) && !s.pending.has(k) && !free.has(k) && k !== bk) fresh.add(k);
   136	        return { cd, fresh: fresh.size, bal: Math.max(cd.a.length, cd.b.length) };
   137	      }).sort((p, q) => p.fresh - q.fresh || p.bal - q.bal || cmpStr(p.cd.ka + p.cd.kb, q.cd.ka + q.cd.kb)).slice(0, opt.maxCand);
   138	      for (const { cd } of scored) {
   139	        nodes++;
   140	        const entries = new Map(s.entries);
   141	        const pending = new Map(s.pending);
   142	        pending.delete(bk);
   143	        entries.set(bk, { key: bk, cells: cc.slice().sort((a, b) => a - b), a: cd.a, b: cd.b });
   144	        for (const [k, p] of [[cd.ka, cd.a], [cd.kb, cd.b]] as const) if (p.length >= 2 && !entries.has(k) && !free.has(k)) pending.set(k, p);
   145	        const child: State = { entries, pending };
   146	        const k = stateKey(child);
   147	        if (!seen.has(k)) { seen.add(k); next.push(child); }
   148	      }
   149	    }
   150	    next.sort((p, q) => size(p) - size(q) || pendingSize(p) - pendingSize(q) || cmpStr(stateKey(p), stateKey(q)));
   151	    beam = next.slice(0, opt.beamW);
   152	  }
   153	  return chain(nodes);
   154	}

   163	/** Independent re-check of a construction DAG against the grammar. Does not use the search code. */
   164	export function validateDag(target: readonly number[], dag: readonly DagEntry[], conn: Conn, free: ReadonlySet<string> = new Set()): Validation {
   165	  const problems: string[] = [];
   166	  const tset = new Set(target);
   167	  const built = new Set<string>(free);
   168	  const keyOf = (cells: readonly number[]) => normalise(toPoints(cells)).join(",");
   169	  for (const e of dag) {
   170	    const aset = new Set(e.a);
   171	    if (e.a.length === 0 || e.b.length === 0) problems.push(`${e.key}: empty part`);
   172	    if (e.b.some((c) => aset.has(c))) problems.push(`${e.key}: parts overlap`);
   173	    const union = [...e.a, ...e.b].sort((p, q) => p - q);
   174	    if (union.join(",") !== e.cells.slice().sort((p, q) => p - q).join(",")) problems.push(`${e.key}: parts do not make the whole`);
   175	    if (union.some((c) => !tset.has(c))) problems.push(`${e.key}: not a sub-object of the target`);
   176	    if (!isConnected(e.a, conn) || !isConnected(e.b, conn) || !isConnected(union, conn)) problems.push(`${e.key}: a part or the whole is not connected`);
   177	    for (const part of [e.a, e.b]) if (part.length >= 2 && !built.has(keyOf(part))) problems.push(`${e.key}: part ${keyOf(part)} is not built yet`);
   178	    if (keyOf(union) !== e.key) problems.push(`${e.key}: key does not match the cells`);
   179	    built.add(e.key);
   180	  }
   181	  const want = keyOf(target);
   182	  if (target.length >= 2 && !built.has(want)) problems.push("target is not built");
   183	  return { ok: problems.length === 0, problems };
   184	}

    62	    for (const [x, y] of pts) for (const [dx, dy] of [[0, -1], [-1, 0], [1, 0], [0, 1]] as const) {
    63	      const nx = x + dx, ny = y + dy;
    64	      if (nx < 0 || ny < 0 || nx >= box || ny >= box) continue;
    65	      const c = ny * box + nx;
    66	      if (!have.has(c) && !fr.includes(c)) fr.push(c);
    67	    }
    68	    fr.sort((a, b) => a - b);
    69	    const c = fr[rnd(seed, step, 0xf0) % fr.length];
    70	    have.add(c);
    71	    pts.push([c % box, (c - (c % box)) / box]);
    72	  }
    73	  return normalise(pts);
    74	}

   107	 * Motif selection: `candidates` deterministic random-grown shapes; keep the one with the highest a; ties by the
   108	 * lexicographically smallest canonical key; keys in `exclude` are skipped.
   109	 */
   110	export function selectMotif(n: number, seedOf: (cand: number) => number, solve: Solver, exclude: ReadonlySet<string> = new Set()): Motif {
   111	  let best: Motif | null = null;
   112	  for (let cand = 0; cand < PROTOCOL.motif.candidates; cand++) {
   113	    const cells = growShape(n, PROTOCOL.motif.box, seedOf(cand));
   114	    const key = canonicalKey(cells);
   115	    if (exclude.has(key)) continue;
   116	    const s = solve(cells);
   117	    if (!best || s.a > best.a || (s.a === best.a && key < best.key)) best = { cells, key, a: s.a, status: s.status, candidate: cand };
   118	  }
   119	  if (!best) throw new Error("no motif candidate survived");
   120	  return best;

   125	/** Slot grid: `cols x rows` slots of pitch (px, py) on the torus, visited in a seeded shuffle that depends only on (seed, replicate). */
   126	function slots(px: number, py: number, seed: number, rep: number): [number, number][] {
   127	  const cols = Math.floor(W / px), rows = Math.floor(H / py);
   128	  const all: [number, number][] = [];
   129	  for (let r = 0; r < rows; r++) for (let c = 0; c < cols; c++) all.push([c * px, r * py]);
   130	  for (let i = all.length - 1; i > 0; i--) { const j = rnd(seed, rep, 0x5107 + i) % (i + 1); [all[i], all[j]] = [all[j], all[i]]; }
   131	  return all;
   132	}

   134	function paint(objs: readonly Placed[], id: ClassId, rep: number): Patch {
   135	  const frame = new Uint8Array(W * H);
   136	  let occupied = 0;
   137	  for (const o of objs) for (const c of o.cells) {
   138	    const x = (cx(c) + o.at[0]) % W, y = (cy(c) + o.at[1]) % H;
   139	    if (frame[y * W + x]) throw new Error(`${id} r${rep}: overlapping cells`);
   140	    frame[y * W + x] = 1; occupied++;
   141	  }
   142	  return { frame, w: W, h: H, meta: { id, replicate: rep, occupied, padding: 0, objects: objs.length, motifs: [], note: "" } };
   143	}

   145	const place = (cells: Cells, slot: [number, number]): Placed => ({ cells, at: slot });
   146	const bbox = (cells: Cells) => { let mx = 0, my = 0; for (const c of cells) { mx = Math.max(mx, cx(c)); my = Math.max(my, cy(c)); } return [mx + 1, my + 1] as const; };

   148	function finish(patch: Patch, motifs: { motif: Motif | { cells: Cells; key: string; a: number; status: string; candidate: number }; copies: number }[], note = ""): Patch {
   149	  patch.meta.motifs = motifs.map(({ motif, copies }) => ({ key: motif.key, a: motif.a, status: motif.status, copies, candidate: motif.candidate }));

   166	/** Smallest offset (by Chebyshev radius, then dy, then dx) that puts a copy of `cells` diagonally against another without any edge contact. */
   167	export function diagonalOffset(cells: Cells): [number, number] {
   168	  const set = new Set(cells);
   169	  for (let r = 1; r <= 14; r++) for (let dy = -r; dy <= r; dy++) for (let dx = -r; dx <= r; dx++) {
   170	    if (Math.max(Math.abs(dx), Math.abs(dy)) !== r) continue;
   171	    let diag = false, edge = false, overlap = false;
   172	    for (const c of cells) {
   173	      const x = cx(c) + dx, y = cy(c) + dy;
   174	      if (x < 0 || y < 0) { overlap = overlap; }
   175	      for (const [ex, ey] of [[0, 0], [0, -1], [-1, 0], [1, 0], [0, 1]] as const) {
   176	        if (x + ex >= 0 && y + ey >= 0 && set.has(code(x + ex, y + ey))) { if (ex === 0 && ey === 0) overlap = true; else edge = true; }
   177	      }
   178	      for (const [ex, ey] of [[-1, -1], [1, -1], [-1, 1], [1, 1]] as const) if (x + ex >= 0 && y + ey >= 0 && set.has(code(x + ex, y + ey))) diag = true;
   179	    }
   180	    if (diag && !edge && !overlap) return [dx, dy];
   181	  }
   182	  throw new Error("no diagonal contact offset found");
   183	}

   185	/** Build one patch. Motif selection is the only expensive step (solver calls). */
   186	export function buildPatch(id: ClassId, rep: number, opt: FixtureOptions = {}): Patch {
   187	  const seeds = opt.seeds ?? PROTOCOL.seeds;
   188	  const solve = opt.solve ?? SHARED_SOLVER;
   189	  const m = PROTOCOL.motif;
   190	  const placeSeed = seeds.place;
   191	  const slotsOf = (px = m.pitch, py = m.pitch) => slots(px, py, placeSeed, rep);
   192	  const motifSeed = (tag: number, k: number) => (cand: number) => rnd(rnd(seeds.motif, tag, rep), k, cand);
   193	  const repeat = (cells: Cells, copies: number, sl: [number, number][]) => Array.from({ length: copies }, (_, i) => place(cells, sl[i]));
   194	  switch (id) {
   195	    case "tile-repeat": return finish(paint(repeat(TILE_MOTIF, 40, slotsOf(4, 4)), id, rep), [{ motif: fixedMotif(TILE_MOTIF, solve), copies: 40 }]);
   196	    case "crystal-lattice": {
   197	      const ox = rnd(seeds.crystal, rep, 1) % (W - 12), oy = rnd(seeds.crystal, rep, 2) % (H - 20);
   198	      return finish(paint([place(CRYSTAL_BLOCK, [ox, oy])], id, rep), [], "one object, bound only");
   199	    }
   200	    case "crystal-spaced": return finish(paint(repeat(SQUARE_4X4, 15, slotsOf(5, 5)), id, rep), [{ motif: fixedMotif(SQUARE_4X4, solve), copies: 15 }]);
   201	    case "random-field": {
   202	      const seen = new Set<string>();
   203	      const objs: Placed[] = [];
   204	      const sl = slotsOf();
   205	      for (let attempt = 0; objs.length < 40; attempt++) {
   206	        if (attempt >= 4000) throw new Error("random-field: attempt cap reached");
   207	        const cells = growShape(m.randomFieldN, m.box, rnd(rnd(seeds.motif, 11, rep), attempt, 0xfe1d));
   208	        const key = canonicalKey(cells);
   209	        if (seen.has(key)) continue;
   210	        seen.add(key);
   211	        objs.push(place(cells, sl[objs.length]));
   212	      }
   213	      return finish(paint(objs, id, rep), [], "40 distinct shapes");
   214	    }
   215	    case "random-dup": {
   216	      const used = new Set<string>();
   217	      const motifs: Motif[] = [];
   218	      for (let k = 0; k < m.dupMotifs; k++) { const mo = selectMotif(m.dupN, motifSeed(21, k), solve, used); used.add(mo.key); motifs.push(mo); }
   219	      const sl = slotsOf();
   220	      const objs = motifs.flatMap((mo, k) => repeat(mo.cells, m.dupCopies, sl.slice(k * m.dupCopies, (k + 1) * m.dupCopies)));
   221	      return finish(paint(objs, id, rep), motifs.map((motif) => ({ motif, copies: m.dupCopies })));
   222	    }
   223	    case "random-dup-hi": {
   224	      const mo = selectMotif(m.dupN, motifSeed(31, 0), solve);
   225	      return finish(paint(repeat(mo.cells, m.hiCopies, slotsOf()), id, rep), [{ motif: mo, copies: m.hiCopies }]);
   226	    }
   227	    case "random-dup-12": {
   228	      const mo = selectMotif(m.matchedN, motifSeed(41, 0), solve);
   229	      return finish(paint(repeat(mo.cells, m.matchedCopies, slotsOf()), id, rep), [{ motif: mo, copies: m.matchedCopies }]);
   230	    }
   231	    case "hier-12": return finish(paint(repeat(COMPOSITE_12, m.matchedCopies, slotsOf()), id, rep), [{ motif: fixedMotif(COMPOSITE_12, solve), copies: m.matchedCopies }]);
   232	    case "hierarchy": return finish(paint(repeat(COMPOSITE_24, 10, slotsOf(9, 5)), id, rep), [{ motif: fixedMotif(COMPOSITE_24, solve), copies: 10 }]);
   233	    case "hierarchy-mixed": {
   234	      const sl = slotsOf();
   235	      const objs = [...repeat(BLOCK_2X3, 10, sl.slice(0, 10)), ...repeat(COMPOSITE_12, 15, sl.slice(10, 25))];
   236	      return finish(paint(objs, id, rep), [{ motif: fixedMotif(BLOCK_2X3, solve), copies: 10 }, { motif: fixedMotif(COMPOSITE_12, solve), copies: 15 }]);
   237	    }
   238	    case "random-scatter": {
   239	      const frame = new Uint8Array(W * H);
   240	      let placed = 0;
   241	      for (let attempt = 0; placed < PROTOCOL.patch.mass; attempt++) {
   242	        if (attempt >= 200000) throw new Error("random-scatter: attempt cap reached");
   243	        const x = rnd(seeds.scatter, rep, 2 * attempt) % W, y = rnd(seeds.scatter, rep, 2 * attempt + 1) % H;
   244	        let free = true;
   245	        for (let dy = -1; dy <= 1 && free; dy++) for (let dx = -1; dx <= 1; dx++) if (frame[((y + dy + H) % H) * W + ((x + dx + W) % W)]) { free = false; break; }
   246	        if (free) { frame[y * W + x] = 1; placed++; }
   247	      }
   248	      return finish({ frame, w: W, h: H, meta: { id, replicate: rep, occupied: placed, padding: 0, objects: placed, motifs: [], note: "" } }, [], "no two cells touch under 8-connectivity");
   249	    }
   250	    case "seam-hier-12":
   251	    case "seam-dup-12": {
   252	      const mo = id === "seam-hier-12" ? fixedMotif(COMPOSITE_12, solve) : selectMotif(m.matchedN, motifSeed(41, 0), solve);
   253	      const [dx, dy] = diagonalOffset(mo.cells);
   254	      const [bw, bh] = bbox(mo.cells);
   255	      const pw = bw + Math.abs(dx) + 1, ph = bh + Math.abs(dy) + 1;
   256	      const sl = slots(Math.max(pw, 12), Math.max(ph, 12), placeSeed, rep);
   257	      const objs: Placed[] = [];
   258	      for (let i = 0; i < m.matchedCopies / 2; i++) {
   259	        const [sx, sy] = sl[i];
   260	        const ax = sx + (dx < 0 ? -dx : 0), ay = sy + (dy < 0 ? -dy : 0);
   261	        objs.push(place(mo.cells, [ax, ay]), place(mo.cells, [ax + dx, ay + dy]));
   262	      }
   263	      return finish(paint(objs, id, rep), [{ motif: mo, copies: m.matchedCopies }], `pairs touch diagonally at offset (${dx}, ${dy})`);
   264	    }
   265	  }
   266	}

    22	## 3. Design
    23	
    24	### 3.1 Grammar (the spec file `GRAMMAR.md` must state each of these)
    25	
    26	- **Substrate.** A patch is a `w x h` torus of small integers. Occupancy: cell occupied iff `value >= tau`. Frozen `tau = 1` primary; `tau in {1,2,4}` only in the sensitivity grid. Matter amount is ignored by the grammar (shape only); mass is controlled at the fixture level.
    27	- **Primitive.** The monomer: one occupied cell.
    28	- **Object.** A finite set of occupied cells, connected under the connectivity rule (3.2), stored as integer offsets from its min corner.
    29	- **Joining operation.** Given two pool members A, B (A may equal B, reuse is free once built), place B at an integer offset relative to A so that cells are disjoint and the union is connected under the connectivity rule; the union is a new pool member. Cost 1 per join. Monomers are free.
    30	- **Restriction (stated, not hidden).** Intermediates must be sub-objects of the target (connected subsets, up to the equivalence group). This is the standard "fragments of the target" restriction; it makes the search finite. The result is the *construction length under this grammar*, not the published assembly index (different primitives, 2D lattice, no chemistry).
    31	- **Construction length `a(O)`**: minimum joins to build O from monomers. Trivial bounds `ceil(log2 n) <= a <= n-1`. Exact for `n <= EXACT_MAX_N` (10) within a node budget; otherwise an upper bound from the search that ran (`bound`, with the node budget recorded). Status field per object: `exact | bound`.
    32	- **Equivalence / copy identity.** Primary group `T` (translation only). Variants `D4` (translation plus the 8 dihedral images). Two objects are copies iff their canonical forms (lexicographically least sorted offset list over the group) are equal. Primary reading uses `T`; `D4` reported as the equivalence-class uncertainty (3.6). Reflection is included in `D4` and flagged, since chirality is a real distinction on a lattice.
    33	- **Torus.** Components are found with wraparound; an object that wraps the full torus in either axis is flagged `spans` and excluded from class tallies (counted, reported).
    34	
    35	### 3.2 Segmentation (object boundaries)
    36	
    37	Primary: 4-connectivity on occupied cells, torus. Variant: 8-connectivity. Both are in the frozen sensitivity grid; the primary is never chosen after seeing scores. Objects with more than `OBJ_MAX_N` (40) cells are scored by the bound only and flagged `large`. Components touching the patch border are not special (torus).

    39	### 3.3 Exact search (toy path)
    40	
    41	For target O with n cells: iterative deepening over join count k = lower bound .. n-1. State = set of pool members (canonical sub-objects of O, closed under the group). A step chooses an unordered pair (with repeat) from the pool whose canonical union is a connected sub-object of O at a consistent offset. Every candidate set is enumerated in a fixed order (cells sorted row-major, offsets sorted) so node counts are deterministic. Prune: pool must be able to reach |O| (largest piece sum bound), dedupe states by sorted canonical-id tuple. Budget `EXACT_NODE_BUDGET`; on exhaustion the status degrades to `bound` and the best known upper bound is returned. Expected exact values are derived by hand in the test file (see 5), not by running the solver: monomer 0; domino 1; I-tromino 2; 2x2 square 2 (two dominoes, one reused); I-tetromino 2 (domino reused); 1x8 line 3 (doubling); 2x4 block 3; plus-pentomino **4** (review finding 2: a 3-join build needs a connected 3+2 partition or a 2-join tetromino plus monomer; the plus allows neither; lower-bound proof in the test comment); L-tromino 2 (translation-only), and a case showing that D4 and T give the same `a` while differing in class counts.

    43	### 3.4 Bounded search (larger patches)
    44	
    45	**Certificate rule:** a reported `bound` is always the join count of a *completed* construction DAG (every target cell reached, every join valid under 3.1) which an independent validator re-checks in tests; a partial path's count is never reported. On budget exhaustion the monomer chain (`n-1`) is the fallback. Ties in the beam break by lexicographic canonical id. Greedy-with-reuse beam: maintain the pool; repeatedly pick the join that completes the largest repeated sub-pattern (copy-aware), beam width `BEAM_W` (8), node cap `BOUND_NODE_CAP`. Always also compare against the trivial `n-1` and keep the min. Output `{ bound, exact: boolean, nodes }`. Patch-level `sharedBound` is defined precisely: the join count of a completed construction DAG that builds every non-`spans`, non-`large` object of the patch, with pool members shared across targets (each pool member a connected sub-object of at least one target); it is a **cost** (lower = more reuse), reported as a separate readout. It is what makes a duplicated motif cheap after the first copy, and it is exactly the quantity we expect to expose duplicated random motifs as low-cost. Tests assert `bound >= exact` on every toy object where both are known, and that the bound is monotone-safe (never below the proven lower bound).

    65	**Matching.** The primary pair `hier-12` vs `random-dup-12` is identical in object size, object count, copy multiplicity and placement; it is the only pair that may carry a `separates` verdict. All other pairs are descriptive, with their size/count differences stated in the evidence. Because exact mass is enforced by construction, tests assert `sum occupied == 240` for every replicate. Where integer division cannot hit 240, the class is padded with isolated monomers and the padding count is recorded (not hidden).

    70	
    71	### 3.6 Readouts (kept separate; no combined statistic)
    72	
    73	Per patch / per frame:
    74	1. `constructionLength`: per class `a` (status exact|bound); patch summaries: sum, max, mean of `a/(n-1)` ("reuse ratio"), and `sharedBound`.
    75	2. `copyCount`: per class and summary (number of classes with copies >= 2, max copies, copy-weighted sum). Under `T` and `D4`.
    76	3. `persistence`: for movie inputs, fraction of classes (by canonical form) present at t that are present at t+dt for `dt in {1,2,4}` frames; static synthetic patches are `n/a`, not 1.
    77	4. `equivClassUncertainty`: number of classes and total copy pairs under `T`, `D4`, and `D4` with 8-connectivity; the spread (max - min) is the uncertainty.
    78	5. **Baselines**: occupied cell count (occupancy), deflate length of the packed patch (reuse `deflateSync` helper conventions and fflate pin from I14 `losses.ts`), object count, mean object size and max-class multiplicity (trivial descriptors, finding 3). All are independent columns and all enter the beyond-baselines gate. Evidence records the fflate version; verdicts depend on deflate only through baseline pair accuracy, re-derived by `--check`.
    79	6. **Incremental value**: for each class pair of interest, exact order-accuracy of each readout and of each baseline over all replicate pairs (fraction of (hier-12_i, random-dup-12_j) pairs ordered in the **declared direction of that quantity**; ties count 1/2; integer rationals). "Incremental over baselines" means a readout orders pairs where occupancy and deflate do not (accuracy minus the best baseline accuracy, rational). It is a discrimination statement on a fixed fixture set, not predictive modelling.
    80	
    81	**Directions are frozen per quantity (finding 4):** `sharedBound` and `reuseRatio` are costs; the declared direction for `hier-12` is **lower** (more reuse than a random motif of equal size). Per-object `constructionLength` and `maxCopies` are declared *not directional* at matched size and multiplicity (tied by design; reported, cannot separate). Baselines are scored in both directions, best direction used (conservative bar).
    82	
    83	**Undefined values (finding 9):** monomers have undefined `reuseRatio` (excluded from means, counted); empty eligible sets give `null`, making the readout verdict `measurement-limited`, never pass or fail. `large` objects (> `OBJ_MAX_N`) are scored by bound only and counted; `spans` objects are excluded and counted.
    84	
    85	**Torus identity (finding 10):** a component is unwrapped by BFS lifting from its row-major-first cell; a revisit at a different lift (winding) marks it `spans`. Canonical forms use lifted offsets, so a domino across a seam equals an interior domino; tests translate fixtures across both seams.
    86	
    87	### 3.7 Sensitivity analyses (reported, never tuned)
    88	
    89	- Segmentation: `{4,8} x tau {1,2,4}` on clips; on synthetic patches `{4,8}` (tau fixed); plus a one-cell dilation/erosion perturbation of every object boundary (deterministic) to measure how many class memberships change.
    90	- Temporal sampling: stride `dt in {1,2,4,8}` frames on movies for persistence and copy count.
    91	- Frozen segmentation-sensitive control (finding 5): `seam-touch` patches (240 cells; objects deliberately diagonally adjacent at scheme-fixed positions) built from the same `hier-12` and `random-dup-12` motifs, so 4 vs 8 connectivity changes object definitions inside the calibration set. The verdict is recomputed for `{4,8}` on spaced and `seam-touch` versions. Clips give descriptive outcomes only: per variant (object count, share of cells in `large`/`spans`, class count); a clip is `segmentation-dominated` if any moves by a factor of 2 or more across the `{4,8} x tau` grid (factor frozen). Temporal-sampling outcomes apply to movies only; static verdicts are `n/a` for sampling, never `stable`.
    92	- Verdict per readout: `stable` if the separation verdict is identical across the grid, else `segmentation-dominated` (resp. `sampling-dominated`). If object definitions dominate, the sensitivity failure is published as the result; no boundary is changed to rescue the treatment.
    93	
    94	### 3.8 Frozen decision rule (in `PROTOCOL.md`, before any clip is scored)
    95	
    96	For each readout R in {`constructionLength` (patch mean per object, and `sharedBound`), `reuseRatio`, `copyCount` (max copies), `copyWeightedConstruction` (naive metric under test, defined as `sum over classes with copies >= 2 of a_class * (copies_class - 1)` so duplication weights it; algebra tested)} and each of the two negative classes `random-field`, `random-dup`, `random-dup-hi`:
    97	
    98	- R **separates** `hier-12` from `random-dup-12` iff, over all `R x R` replicate pairs, the score is ordered in R's declared direction in every pair (accuracy = 1) under the primary grammar, **and** the same strict ordering holds in the segmentation grid.
    99	- If `random-dup`, `random-dup-hi` or `random-dup-12` scores as strongly as the weakest `hier-12` replicate on R (secondary `hierarchy` reported separately): verdict for R = **`fails to separate`**, and the report states in those words that no life-detection claim is made from R.
   100	- If the verdict differs across the sensitivity grid: `segmentation-dominated` and published as a sensitivity failure.
   101	- A readout that passes must additionally beat the best of occupancy and deflate baselines on pair accuracy to be called `adds value over simple baselines`; otherwise `separates, but not beyond baselines`.
   102	
   103	Expectation, declared before running (so surprises are visible): the naive `copyWeightedConstruction` fails against `random-dup`/`random-dup-hi` vs secondary `hierarchy`; `maxCopies` cannot separate at matched multiplicity; `reuseRatio` and `sharedBound` may separate; neither is allowed to be tuned after seeing it. Thresholds (the accuracy-1 requirement, grids, `R`, `M`) are fixed in `PROTOCOL.md`; any change needs a dated amendment file, never an edit.

   166	/** Smallest offset (by Chebyshev radius, then dy, then dx) that puts a copy of `cells` diagonally against another without any edge contact. */
   167	export function diagonalOffset(cells: Cells): [number, number] {
   168	  const set = new Set(cells);
   169	  for (let r = 1; r <= 14; r++) for (let dy = -r; dy <= r; dy++) for (let dx = -r; dx <= r; dx++) {
   170	    if (Math.max(Math.abs(dx), Math.abs(dy)) !== r) continue;
   171	    let diag = false, edge = false, overlap = false;
   172	    for (const c of cells) {
   173	      const x = cx(c) + dx, y = cy(c) + dy;
   174	      if (x < 0 || y < 0) { overlap = overlap; }
   175	      for (const [ex, ey] of [[0, 0], [0, -1], [-1, 0], [1, 0], [0, 1]] as const) {
   176	        if (x + ex >= 0 && y + ey >= 0 && set.has(code(x + ex, y + ey))) { if (ex === 0 && ey === 0) overlap = true; else edge = true; }
   177	      }
   178	      for (const [ex, ey] of [[-1, -1], [1, -1], [-1, 1], [1, 1]] as const) if (x + ex >= 0 && y + ey >= 0 && set.has(code(x + ex, y + ey))) diag = true;
   179	    }
   180	    if (diag && !edge && !overlap) return [dx, dy];
   181	  }
   182	  throw new Error("no diagonal contact offset found");
   183	}

   164	export function validateDag(target: readonly number[], dag: readonly DagEntry[], conn: Conn, free: ReadonlySet<string> = new Set()): Validation {
   165	  const problems: string[] = [];
   166	  const tset = new Set(target);
   167	  const built = new Set<string>(free);
   168	  const keyOf = (cells: readonly number[]) => normalise(toPoints(cells)).join(",");
   169	  for (const e of dag) {
   170	    const aset = new Set(e.a);
   171	    if (e.a.length === 0 || e.b.length === 0) problems.push(`${e.key}: empty part`);
   172	    if (e.b.some((c) => aset.has(c))) problems.push(`${e.key}: parts overlap`);
   173	    const union = [...e.a, ...e.b].sort((p, q) => p - q);
   174	    if (union.join(",") !== e.cells.slice().sort((p, q) => p - q).join(",")) problems.push(`${e.key}: parts do not make the whole`);
   175	    if (union.some((c) => !tset.has(c))) problems.push(`${e.key}: not a sub-object of the target`);
   176	    if (!isConnected(e.a, conn) || !isConnected(e.b, conn) || !isConnected(union, conn)) problems.push(`${e.key}: a part or the whole is not connected`);
   177	    for (const part of [e.a, e.b]) if (part.length >= 2 && !built.has(keyOf(part))) problems.push(`${e.key}: part ${keyOf(part)} is not built yet`);
   178	    if (keyOf(union) !== e.key) problems.push(`${e.key}: key does not match the cells`);
   179	    built.add(e.key);
   180	  }
   181	  const want = keyOf(target);
   182	  if (target.length >= 2 && !built.has(want)) problems.push("target is not built");
   183	  return { ok: problems.length === 0, problems };
   184	}
