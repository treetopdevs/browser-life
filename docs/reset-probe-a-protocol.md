# Probe A: prospective observation protocol

Date: 2026-09-29. Status: implementation specification awaiting controls, final source freeze and G1 review. No classified historical outcomes have been inspected. This document narrows the supported claims; it does not silently relax the broader entity contract.

## Primary question and fixed sample

Re-examine all 200 original Test 1 links, with unchanged historical mutation and physics. The primary endpoint is immediate preceding-census copy attribution, not a binary reproduction label. Retain every original row and its budding/fission, clonal/mutant and history strata. Ten source histories are the independent units. Missing parent support, missing descendant support, unknown ancestry, technical failure and observed loss are distinct statuses.

At event time t, identify the original parent support in the actual historical census at t−100. Its membership must come from authenticated common observer state and physical components, never nearest same-genotype matching. At t, identify the original child's support using the replayed historical observer. The original classifier uses B+P ≥48, component mass ≥256 and four-neighbor toroidal connectivity.

For each genome-bearing site in that child support, query the uninterrupted copy path to its site at t−100. Report parent, known nonparent and unknown counts, with all sites retained in the denominator. Parent attribution interval is [parent/N, (parent+unknown)/N]; if N=0 the endpoint is unavailable. Also report all physical support sites and genome-free sites separately. Record the fraction weighted by present B+P, naming it **current bound mass associated with copy origins**. It is not an inherited-material fraction. Do not impose a majority threshold or translate these fractions into propagule/invasion classes.

The exact mutation ledger is retained. Effective/clamped/transient status is recorded only when the necessary before/after evidence exists; unretained earlier-step effects are unavailable. Mutation preserves the copy path regardless of whether the genotype changes.

## Connectivity and follow-up

Report physical connectivity separately from historical tracker identities. Evaluate both threshold48/four-neighbor topology and threshold1/eight-neighbor topology within each toroidal tile. Do not discard small components when checking bridges. Threshold1 is a sensitivity analysis: tenuous bridges can connect otherwise meaningful structures, so a connection does not refute individuality.

At t and every100steps through t+1000 (11 samples), report connectivity and descendant-associated support persistence. This supports only **disconnected at all sampled censuses**, never continuous separation. Missing samples remain unavailable. Sampling ends before the existing million-step history boundary for all original links, but the implementation must validate this rather than assume it.

For budding, the comparison is the current component retaining the attributed parent ID. For fission, the comparison set is the component retaining the parent ID plus every additional daughter in the exact fission event except the focal child. The retained parent ID is a historical candidate branch, not proof that a biological parent survived. Identity must be followed through explicit copy paths. A reference that cannot be followed independently of the tracker's overlap assumption is unavailable. Separate pre-existing low-threshold support from an observed geometric split; crossing a tracker threshold alone is not a newly demonstrated split.

Keep two distinct references: the parent at t−100 for birth attribution, and the focal child plus each comparison branch at t for follow-up. To follow event-specific copy ancestry after census resets, compose successive exact site-origin maps while retaining each pending event's reference memberships. Parent-origin copies outside the focal child cannot establish child persistence. If multiple reference branches occupy one later physical component, report shared support/contact; do not assign exclusive identity. Do not substitute the latest reset's site index for an earlier event origin. Freeze referenceStep and support membership hashes. A copy-path family can persist while the material-bearing entity changes; therefore name the endpoint **descendant-associated support persistence**, not viability, reproduction or maintained metabolism. Reconstruction, repeated reproduction and fitness remain unavailable unless separately tested.

Total material origin remains unknown when recycling and mixed reactions erase identity. This is a substantive inference limit: even complete copy attribution plus disconnected support cannot distinguish offspring construction from copy spread through pre-existing material. Do not decide the rule target from this partial evidence alone.

## Bounded continuous-window check

Before outcomes, assign history h (1..10) the window starting at 100000 + 70000×(h−1), of length1000steps, plus100steps follow-up. Selection does not consult the birth list. History1's start state has previously been used for engineering timing and component-size measurements; no biological label was developed there.

Within these windows, inspect physical connectivity and local copy ancestry at every step. Flag candidate fragmentation when a preceding support contributes copy paths to at least two current disconnected supports, each with bound mass≥256, under threshold1/eight-neighbor topology. Preserve transient candidates and failed fragments. For each raw flag at step s, freeze and hash each qualifying branch's support at s. Compose its copy paths through the next100 one-step maps, scoring each of s+1 through s+100 under threshold1/eight-neighbor topology. Report known-copy persistence and disconnection, shared support, unresolved copy origin and observed copy loss separately. The initial flag geometry is recorded separately from these100 future samples. A persistence descriptor is complete only with all100 required observations; missing samples yield an explicitly incomplete descriptor. This is a copy-associated support descriptor, not entity viability or reproduction. Multiple flags remain separate observations even when their supports overlap. Retain the bounded rolling evidence in memory; no full per-cell disk history is required. Runtime/storage caps can stop an affected run with partial evidence, but there is no outcome-based candidate-count cutoff. These are candidate copy-associated separations, not certified births. Preserve every per-step candidate flag without grouping flags into unique episodes. Consecutive fragmentation flags, fusion and reseparation therefore remain separate observations; no unique-event rate is reported. For each flag, record only whether the enclosing interval (100×floor((step−1)/100), 100×ceil(step/100)] contains an ordinary tracker fission or budding. Interval co-occurrence is not event correspondence. Explicit support-level matching and episode counts remain unavailable in this minimal check. Flags in intervals with no tracker link are leads for possible omissions, not proof of missed biological reproduction. Annotate contributions into components with pre-existing bound support at the preceding step; this is not offspring construction. Handle torus crossing, diagonal contact, existing neighbors and fusion explicitly. Report actual coverage and all ambiguity; no universal recall estimate.

## Controls and analysis

Before G1, constructed observation controls must cover true geometric split, same-lineage pre-existing neighbor, threshold flicker, torus crossing, diagonal contact, transient contact between census times, fission without parent survival, fusion, mutation during descent and minority-material genome winner. Scripted geometry validates observation logic; executed physics and CPU/GPU comparisons validate the sidecar. Neither establishes natural reproduction. Keep the layers identified in the report.

Report all200 rows with numeric attribution, connectivity samples, support persistence, mutation coverage and unresolved material origin. Summarize each history first, then pooled descriptive counts, retaining strata and unavailable denominators. Worst-case attribution intervals carry unknown copy paths. If uncertainty intervals are used, resample whole histories; do not present 200 rows as independent samples. No significance threshold or automatic mechanism decision is specified.

## Execution gate

Whole-history replay from0 is provisionally preferred. Approve it only after the completed common-observer benchmark, source-byte freeze, independent review and prospective phase reallocation if required. Verify physical and complete common-observer artifact hashes at all available original checkpoints. The unpersisted historical lineageObs auxiliary state must not be falsely claimed checkpoint-resumable. Keep compact event evidence and continuous-window summaries, not per-cell histories on disk.

The run manifest must name exact source bytes, all input hashes, reference intervals, graph definitions, follow-up windows, failure handling, storage/time caps and attempt IDs. Stop on drift, parity error, dropped mutation events, bad controls or exhausted caps. Technical failure never substitutes a sample. Paid compute requires the separately documented coordination and budget entry. No scientific launch is authorized by this draft alone.
