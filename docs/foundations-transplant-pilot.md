# Bounded transplant feasibility pilot

`tools/foundation-transplant-pilot.ts` is restricted to the authenticated M4 `gradient-m3/treatment/seed-1` replay at 100,000, 500,000 and 900,000 steps. It requires the verified cache, the previously written extraction catalog, the unchanged original bundle, and the frozen extraction rule file. It rehashes the source bundle, rule, catalog, replay implementation and selected pilot implementation files; rechecks all cached checkpoints; and recomputes the full catalog at each time before accepting any selected component. Source, catalog, rule and code are checked again before a plan is published and after execution. An output directory is reserved with create-new semantics and is never resumed or overwritten.

Default mode creates only a CPU-validated plan and starts no GPU work:

```text
deno run -A tools/foundation-transplant-pilot.ts \
  --source /absolute/path/to/original/seed-1 \
  --cache /absolute/path/to/verified/replay-cache \
  --catalog /absolute/path/to/extract-gradient-seed-1-v1.json \
  --rule /absolute/path/to/foundation-extract-feasibility-rule.json \
  --out /absolute/path/to/new/pilot-directory
```

The plan fixes all **18** selected candidates: six at each source time, ordered by time then component index. Candidate `j` (zero based) receives garden seed `630000101 + j`. Each plan row includes exact source indices, packet SHA-256, cell count, per-resource inventory, toroidal placement, and a complete proposed import/export audit. Missing, mismatched or non-clean selections fail validation; the denominator is never silently reduced. Pre-GPU extraction/excision/restoration of every candidate must reproduce its entire source state, including raw cells/genomes, MOT and ledgers.

The plan also fixes **two separate controls before any candidate outcome**, outside the 18-candidate denominator. Both use fresh seed `630000201`, the same 256×256 garden configuration, a 3,000-step window and 100-step censuses. The `m3-founder-9` garden-feasibility comparator uses M3 founder genome **array index 9**, recorded with the M3 founder-set ID, in the standard evaluator disc at `(128,128)` with radius `floor(64/6)=10`, mean biomass 64, energy 128, and nutrient 32. The evaluator's `buildWorld` function assigns seeded per-cell biomass within that disc. The `zero-controller` passive-controller reference is a clone of that exact physical initial state with the same lineage IDs, `mu`, `sigma`, and `motGain`; only its 160 controller weights are zeroed. Neither is preclassified as viable or nonviable. Their resources are checked for equality and their distinct initial physics hashes are recorded before device acquisition.

Execution is separately gated by `--execute --max-seconds N --max-candidates K`, with `0 < N ≤ 600` and `1 ≤ K ≤ 18`. The cap covers validation, GPU work and final rechecks. With `K < 18`, remaining candidates are marked `not-run-limit`; this is an explicitly partial screen and cannot be reported as a population estimate. A capped candidate is marked `incomplete-time-cap`, with completed censuses retained, rather than treated as a failed viability observation. Actual extinction at the full window end is a completed biological observation. The manifest records actual Deno version, OS, architecture, the adapter used to create the device, total elapsed time, and whether the cap was exceeded. No confirmatory M4 seeds are used.

Phase 1 is a **mechanical restoration sham** at each checkpoint. The program restores all six selected packets in memory and checks exact identity. For each time it then runs one untouched source-state continuation and one restored-source-state continuation for 500 steps, using the original configuration, seed, absolute step and observer state. Both must conserve matter and energy and end with the same physics hash, full artifact hash and six observation-file hashes. The source must have an explicitly authenticated **combined physics-and-observer artifact** terminal hash. A mismatch stops the garden phase. This checks that the code path is lossless; it cannot show that removal and placement into a fresh world preserve viability.

Phase 2 runs the **two controls first**, followed by every attempted **intact** packet separately in a fresh, resident-free 256×256 world. The packet gardens keep the source physical configuration except for a new deterministic seed and the registered overrides `mutRate: 0`, `lightMode: uniform`, `lightBase: 40`, `lightAmp: 160`, `seasonAmp: 0`. Each packet world starts at step zero with nutrient A=32 in every cell, neutral ambient MOT, zero other channels and zero cumulative ledgers. A toroidal translation maps the packet's lowest source index (the declared anchor) to cell `(128,128)`. The sole source lineage is explicitly relabelled to `0:1`; all other genome words and all seven physical channels retain their exact packet values. Any displaced garden chemistry is recorded as export, and every resource is reconciled as `after = before + import − export` before the 3,000-step run. The runner and tracker use a 100-step census and the repository's 48/256 component thresholds. Biological extinction of either control is a completed control result; a technical or conservation failure stops candidate execution.

Each census records focal labelled biomass B, focal polymer P, B+P, the number of cells with **focal B>0** (`focalBiomassCells`), focal membrane fraction `P/(B+P)`, qualifying components, tracker fissions/fusions/buddings, and birth/death/fission/fusion/budding event counts. Matter and energy residuals are required to remain exactly zero, and mutations must remain zero. The minimal survival indicator is **focal B>0 at step 3,000**. `positiveGrowth` means final focal B exceeds the placed B. `polymerAtFinalThreeCensuses` means focal P is positive at each of the final three censuses. Their conjunction is labelled literally `growthWithLatePolymer`; polymer is not assumed necessary for self-maintenance, and this outcome is neither a life cycle nor heredity proof. If all 18 candidates fail to persist and the founder comparator also fails, the garden has not shown that it can support the source founder; no substrate or genotype incapacity inference follows. The zero-controller reference is a passive comparison, not a presumed dead state. This source history and its 18 nested components are one feasibility screen. Unequal intact packet biomass, energy and morphology prevent matched competition or comparative fitness claims.
