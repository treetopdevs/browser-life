## Architecture and exact mechanics
Keep existing particle model/version4 unchanged. A new BondedWorld composition wrapper owns an ordinary ParticleWorld and undirected bonds keyed by sorted stable particle IDs. Three modes: none, chains(maxdegree2), mesh(maxdegree4). Same seed, pursuit preset, mutationon and still food. The wrapper is a separate version1 toy extension, not a picker recipe or migration. Snapshot includes base snapshot and bond rules/state; observations cannot resume.

For each living tick: remove dead-end bonds; remove edges whose minimum-image torus distance exceeds0.12; form same-family bonds from unbonded pairs within0.06, sorted by distance then IDs, respecting degreecap. All existing edges exert equal/opposite velocity impulses along the minimum-image direction: clamp(0.08*(distance-0.045), -0.0015,0.0015). Sum using the same pre-impulse positions, then add to velocities before calling base.step(). Base movement/drag/speed clipping and movement-energy cost still apply. No spring potential-energy or conservation claim: this is supplied steering. No extra RNG draws. None mode directly delegates, with zero physical writes. Remove edges whose endpoints died during the tick before reporting. Newborns can connect on the next tick. Count formation, stretch-break and death-removal separately. Store bornTick and endpoint IDs; no self/duplicate/cross-family edges; <=degreecap and finite states. Zero-distance edges exert no impulse. Empty worlds remain frozen without rescue.

Use shared exported rules/constants, and a single graph-summary function. Components mean graph-connected particles, not independent organisms. Report isolated particles separately, component count(size>=2), largest component, edge count/age, births/breaks/removals, base population/families and energy ledger residual. Connections themselves are not inherited; individual movement traits are. Graph joining/splitting is not reproduction.

## Integration contract
BondedWorld(seed,preset,mutation,mode) exposes readonly base:ParticleWorld plus tick/particles/food/history/environment getters, step(), census(), graphSummary(), and snapshot(). Snapshot nests base.snapshot() with extension rules/version/mode, edge records and graph summary; none-mode comparison tests compare the base payload to an ordinary world. Shared renderer uses a narrow structural view type rather than ParticleWorld's private members. Comparison clock needs only particles and step; change its type signature, not runtime algorithm. Optional renderer worldFactory(settings,slot), overlay(ctx,world,size) and text summary callback keep bond-specific imports out of existing pages. Three supplied environments remain still; mode is explicitly recorded separately in bond snapshots and page copy.

Formation is deterministic nearest-first, with stable endpoint-ID ties, and may bias which equally eligible neighbor receives a link. Link capacity and spring steering are supplied engineering. Each bornTick is the tick when formation occurs (world.tick+1); age in completed ticks is world.tick-bornTick+1. Snapshot/statistics are post-step, after death cleanup. A stretch that occurs during a base step is detected at the next step, and this ordering is disclosed. Degree cap applies per endpoint, not per family. Component size includes linked particles only; no-edge largest component is0. Components never become a unit of reproduction or mutation.
