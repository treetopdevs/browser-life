Add a deliberately supplied nutrient conveyor that returns dissolved nutrient from the deep region to the light. It transports nutrient only, not biomass or detritus: it is a selective engineered pump, not fluid physics or an evolved trait. No new biomass, rescue seeds, growth tuning or hidden material source.

Four matched tanks: closed/still, closed/current, rain/still, rain/current. All start from the same seeded stocks and phases as the original aquarium. ## Exact current

64x48 grid partitioned into four16x48 columns. In each column, nested clockwise rectangular rings cover every cell exactly once. For x,y: column=floor(x/16); localX=x%16; layer=min(localX,15-localX,y,47-y). Ring bounds left=16*column+layer,right=16*column+15-layer,top=layer,bottom=47-layer. Clockwise successor: top edge except top-right goes east; right edge except bottom-right goes south; bottom edge except bottom-left goes west; left edge except top-left goes north. Corner priority is exactly that order. Every ring has width>=2,height>=34, so no degenerate case. Each successor is an adjacent cell; no crossing column/world boundaries in this phase. Existing relaxation still crosses columns and the horizontal world seam normally.

When current enabled and tick%4==0, immediately after rain and before nutrient relaxation, synchronously move **all** nutrient at each tile to its successor: nextN[successor(i)]=oldN[i]. This is a bijective permutation, hence exact nutrient conservation/nonnegativity and no concentration beyond an existing pool value. Apply once from old values, never in place. Increment `circulated` by sum(oldN), cumulative nutrient unit-moves, not a pool transfer or created matter. Current off performs nothing and keeps this counter0. Rain at tick8 enters the top row before circulation, so its units participate immediately. All other original rules are unchanged, including mortality before extension, halfwidth24 light, recycle period24 and continued physical updates after extinction. Sediment remains0 here.

Four columns rather than one whole-tank ring ensure every nested ring reaches the upper growth zone and the bottom recycling zone. This geometry is designed up front for delivery; it does not guarantee survival. Circulation period4 is fixed before seeing results. No rate sweep in this slice.
