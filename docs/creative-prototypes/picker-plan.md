## User outcome
At `/particles/picker/`, compare three genuinely different movement recipes at the same seed and tick. Keep one worth watching, optionally say why, and generate two small recipe variations around it. Repeat and save the selection history. Human preference breeds recipes; organisms still reproduce and mutate inside each world. Label those two processes separately.

## Bounded design
- Recipe is an explicit validated 3×3 attraction matrix [-1,1], alignment [0,.2] and food renewal [.3,1]. Presets supply defaults. Default existing `/particles/` trajectories must remain unchanged.
- Extend ParticleWorld with an optional recipe argument; clone/validate/freeze it, export every actual setting. Same-runtime seed repeatability, no resumable checkpoint claim. Toy versioning distinct from research RULE_VERSION. Preserve old pilot as historical evidence; make current evidence provenance explicit.
- Three worlds progress in lockstep by simulation tick with a bounded frame budget. An extinct world stays empty; it does not block comparison of living worlds. Start paused under reduced motion, pause when hidden, keep all counters in sync. Seed and recipe controls reset all worlds explicitly; never compare different ages silently.
- First slate is the three presets, ordered with the chosen starter first. Keep preserves the chosen recipe exactly as new baseline and restarts all three at tick zero with the same seed. Children get new immutable IDs and parent IDs. Mutation RNG for recipe breeding is separate from organism RNG; breeding cannot depend on frame timing or census calls. At least one recipe coordinate changes in each variant even at parameter bounds.
- Selection record includes all candidate recipes, chosen ID, seed, evaluation tick, optional reason, and next slate. Export is a versioned recipe-selection document, not simulation state. Show a concise visible history. No silent deletion: limit 30 selections and clearly stop breeding at the limit; the visitor can export and start a new session.
- Import validates file size (128 KiB), version, every finite bounded parameter, seed, IDs/relationships and history limits before atomically replacing the current session. Invalid input leaves the running session untouched. Display imported text through textContent only. Imported valid sessions restart at tick zero paused; they do not resume particle state.
- Keep page local/diagnostic. Existing production /particles exclusion covers nested picker; add picker assets to exclusion if named separately. Link existing particle page to picker and back.
