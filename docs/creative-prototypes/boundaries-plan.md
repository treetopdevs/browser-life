## Model contract, before implementation
New standalone Float64, same-runtime seeded model, version1. Size64×64 unit-spaced periodic square grid; four-neighbor topology. Fields B(density proxy), N(nutrient proxy), W(supplied wall strength) lie in[0,1]. Modes smooth, walls, threshold, both. No genomes, particles, organism identities or biological reproduction are implemented here.

Use synchronous updates from old arrays, dt=.25. Diffusion coefficients DB=.16 and DN=.30. Compute each undirected east/south edge once and add equal/opposite flux to endpoints. Biomass flux is blocked if either old endpoint has W>=.55 in wall-enabled modes; nutrient flux never blocked. Non-wall modes W stays exactly0. Preserve periodic seams and isotropic reciprocal edge handling.

Let F(x,y)=.01+.05*(.5+.5*sin(2pi*x/64)*cos(2pi*y/64)), fixed across seeds/modes. Smooth B reaction is .20*B*N*(1-B)-.015*B. Threshold reaction is .70*B*(B-.25)*(1-B)*N-.015*B. Different growth coefficients are intentional different rule recipes, not a single-factor causal assay. Nutrient reaction is F*(1-N)-.10*B*N. Density/nutrient reactions and diffusion use only old B/N/W. New B/N are clamped[0,1]; density below.0001 becomes0. Account separately for density reaction, diffusion residual, clamp adjustment and floor loss so change in total B reconciles numerically. This is open matter/energy phenomenology, not conserved research physics.

In wall modes, new W=clamp(old W+dt*(.80*old B*max(abs(old B-neighbor old B))-.01*old W),0,1). Walls are engineered boundary reinforcement, not evolved membranes; no transfer of B to W or matter claim. A hard wall changes biomass transport only, not local reactions or nutrient diffusion. New walls affect flux starting the next tick. No reseeding, spontaneous mutation, external disturbances or hidden rescue.

Initial condition per seed: seeded RNG generates six Gaussian blobs (centers uniform on torus, radius3–5 cells, peak contribution.75), add background .02 and small uniform noise[0,.01], clampB<=.95. N starts.8 everywhere, W starts0. Use Mulberry32 with uint32 state, including seed0. Draw x, y, r for each of six blobs first (x/y=64*rng(), r=3+2*rng()); contribution is .75*exp(-periodicDistanceSquared/(2*r*r)). Then draw one noise value per cell in row-major order; consume identical draws for all modes. Radius here is Gaussian standard deviation, with no cutoff. All four modes have bit-identical initial fields. Snapshot includes full fields, recipe/rules, seed, tick and accounting, observation only notresume. If B becomes exactly allzero, record extinction tick and freeze allfields; comparison clock maycontinueforothermodes. step(n)=n single steps, validate integerbounded count.

## Integration and measurement details
Core path apps/lab/src/boundaries/model.ts exports BoundaryWorld(seed,mode), BOUNDARY_RULES, modes smooth/walls/threshold/both, getters tick, density/nutrient/wall Float64Arrays, size, extinctionTick, history, step(), census(), snapshot(). Census includes densityTotal, nutrientMean, activeCellFraction, components (only regions>=4), tinyComponents, largestComponent (0 when no qualifyingregion), neighborContrast and blockedEdgeFraction. Use fixed0–1 rendering scales, not per-frame auto-normalization. Neighbor contrast and blocked-edge fraction use the same 8192 unique east/south edges as diffusion; contrast is mean absolute B difference and blocked fraction is count of biomass-blocked edges divided by8192.

Census sampled-change is the most recently completed sampling interval, represented as {fromTick,toTick,meanAbsDelta}|null, computed before updating the previous-sample field copy. At ticks between samples, UI labels this last interval instead of implying a fresh100tick measurement. Exact extinction can close a shorter interval. History is bounded to300 samples and disclosed; CLI retains its full scheduled samples. No component identities/split events inferred.

Biomass accounting: expected=initial+reaction+diffusionResidual+clampAdjustment-floorLoss. Clamp adjustment is signed; floorLoss is positive. Also require everytick absolute diffusion-sum residual<=1e-10 separately so an asymmetric flux bug cannot hide in the total ledger. Deltas use old arrays and wall gating is reciprocal. Model holds no mutable references to caller inputs. Constructor validates seed uint32 and knownmode; step count0..100000 integer. Exports explicitly describe proxies and lack of heredity.
