## Implementation review decisions

The bounded three-seed replay is an explicit integration gate, exposed with the archive verifier as `pnpm verify:ecosystem` (Node 24 and ffprobe required). It is intentionally separate from the fast default Vitest suite. It has been executed; this is not merely a raw-record comparison. Keeping the runtime-specific gate explicit avoids making every unrelated unit-test run depend on Node 24 or multimedia tools.

Retry is a user-requested playback action and will be labeled accordingly. Archive failures must persist through failed retries, clear only on confirmed recovery, and distinguish deliberate pause cancellation from media failures. Playback speed must survive reload, frame callbacks must not accumulate, and chart labels and textual alternatives must remain usable on phones.
