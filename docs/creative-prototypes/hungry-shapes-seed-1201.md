# Hungry shapes pilot evidence

Fixed descriptive evidence for seed 1201, mutation on, generated by Node 24.2.0 on darwin/arm64.

The three worlds share founder setup and initial food. Scarce modes offer 768 food units per five-tick pulse; original mode keeps its existing supply. Pulse 0 executes at tick 5 before feeding. Offered food is budget times executed pulses; overflow is not deferred. Worlds stop advancing at extinction.

Censuses are retained every 20 actual ticks and at extinction. Full states are retained at milestone ticks while alive, plus the terminal state at its actual tick. Per-tick late-window rows are retained only for executed ticks 2501–3000; the cap fraction uses a fixed 500-tick denominator with post-extinction ticks counted as zero cap occupancy.

Each mode was run from two independent initializations. Full state, census, and food accounting match at every retained census/milestone and at the end. Both runs received per-tick safety validation for body connectivity, occupancy, caps, integer bounds, lineage, energy conservation, and food accounting. Original mode is checked against the retained development pilot at ticks 0, 1000, 2000, and 3000 when that seed is available.

The visual comparison is a manual parent decision using fixed-camera frames at 500, 1500, 3000 (or actual terminal tick), checking occupied space, patch-mask occupancy, clusters/separated bodies, and gaps. This artifact does not automatically promote or extend any condition.
