# Founder-policy experiment record

This is a genome-level policy comparison under unchanged RULE_VERSION 1. Organism reproduction and material ancestry remain unresolved. The historical Variation verdict does not select a mechanism.

**Closed: the complete pilot failed its frozen gate; the comparison was not launched.** See [findings and decision](pilot-findings.md). Paid spending was $0.

## Authoritative pilot

- `pilot-release.json`: root release, source hashes, runtime and scope.
- `pilot-freeze/`: self-contained executed source and pinned input snapshots. Do not edit this directory’s code or protocol after release.
- `pilot-freeze/experiments/founder-policy/v1/pilot-design.json`: frozen input, cohort, configuration, threshold and seed manifest.
- `pilot-freeze/experiments/founder-policy/v1/pilot-results/`: individual results, deterministic replay and invocation receipts. Partial results are not a passed pilot.

- `frozen-design-check.json`: outcome-independent roster checks.

`design-preflight*.json` are preserved development outputs, superseded by the frozen pilot manifest. They authorize no execution. The live command is developed separately from the frozen pilot; the full comparison needs its own reviewed release, complete-roster cost forecast and source freeze.

## Claims and stopping

The pilot assesses survival, symmetry and discrimination of predetermined controls. It cannot establish a founder-policy effect. A failed biological control is not permission to search for favorable genomes, settings or thresholds. One repair is allowed only for an identified technical defect, using disjoint repair seeds. No comparison may start on a failed or incomplete pilot.

The comparison, if released, is conditional on the archive’s inherited search bias. Unavailable competitive performance is bounded, never silently assigned a loss or replaced by another survivor. Ancestry retention is reported separately.

The reviewed live command implements all four stages. Its later code additions do not replace the archived executed pilot sources. [Recorded founder traits](cohort-recorded-traits.json) preserve screening regeneration observations without using them to rank cohorts.
