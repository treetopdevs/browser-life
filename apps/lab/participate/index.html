OPTIONAL / COMPUTE

Help run the experiments

An island is a browser tab that runs assigned simulation segments and uploads results for comparison. This is the current compute network; the persistent garden with creatures migrating between visitors is a future direction.

01

Check your browser

You need WebGPU and a secure site. A GPU self-test checks this browser against the CPU reference before its work counts.

02

Choose Join

Opening this page does not start compute. On the island page, pressing Join requests work from the coordinator. The tab may use significant GPU time and power while running.

03

Stop whenever you like

Press Stop or close the tab. Completed work and uploaded results remain with the coordinator. See the privacy page for the details sent.

READY WHEN YOU ARE

Open the island runner

The runner shows its connection and current activity. You make the final Join choice there.
