FIELD GUIDE / 01

How the world works

Local rules, light, matter and inherited traits. Start a world, disturb a pattern, and watch what grows back.

THE SUBSTRATE

Cells and resources

Each cell occupies a position in a grid and carries material, energy, and a set of inherited numeric weights. Light supplies energy. Matter moves and changes form within the world. A ledger checks that the accounting balances as the simulation advances.

The rules use integer arithmetic so identical starting states can be checked against a CPU reference and replayed bit for bit on supported GPUs.

WHAT WE OBSERVE

Individuals are measured

The starting patterns carry genomes, but the program does not declare where an organism begins or ends. It tracks connected structures, lineages, splitting, merging, mutations, resource roles, and recovery after a lesion. Those labels are measurements of patterns produced by the rules.

Those measurements have limits. A recent check found that the parent the tracker credits with a birth often contributed no copied material, so tracked births are not treated as proof of reproduction on their own.

An attractive image can be a great reason to keep exploring. When we want to explain a behavior, repeated runs and controls help separate a promising impression from a repeatable effect.

TRY IT

Make a world, then change something

  1. Open the lab and choose a preset and seed.
  2. Press Play. Look for a body, a moving edge, or a pattern that keeps returning.
  3. Switch to Inspect and click a cell; then try a lesion.
  4. Create the same world again with the same seed. Does the pattern return? Save a checkpoint if you want to revisit it.
