Privacy · what the code does today

Your world stays yours.

Exploring the lab and lending compute are different choices. The island runner starts only when you press Join.

In the lab

Everything runs on your device

The lab computes the world in your browser. Copies you save are written to this site's private browser storage. Download writes a file to your own device; Open a file reads one you choose. Clearing site data may remove saved copies.

The public pages and the lab add no analytics service, account, or email collection. The one typeface is served from this site, not from a font network.

If you join

What the island sends

When you press Join on the island page, the browser connects to the coordinator, receives work, and uploads simulation results. It sends a browser user-agent string and GPU adapter description. The coordinator records an island ID, timestamps, run counts, verification counts, and uploaded run artifacts. A temporary bearer credential is kept in this tab's session storage to recover from a reload.

Close the tab or press Stop to stop new work. Uploaded results remain on the coordinator; this project currently has no automatic retention or self-service deletion feature. The public status page shows only aggregate counts.
