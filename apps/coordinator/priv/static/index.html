Archipelago coordinator

Runs are split into segments; a fraction is replayed on a different island and must match bit for bit. This operations view needs the administrator token in production. It only reads: keeper actions are shown as commands to run yourself.

Totals

Segments by status. Pending includes every garden's future days, which wait for their dawn by design; "done, not verified" leaves out verified segments (the tables below count verified segments as done too). Device types that ran work counts adapters of islands that ran or replayed something.

Experiments

Open is segments minus done, diverged, failed and blocked: pending or running. A pending segment may be waiting for its predecessor, a metapopulation barrier, a garden's dawn, an island's pending cap or an island that can run it.

Runs

Open work by capability

Work of every experiment but the gardens, by the capabilities its run needs (replays need the same). A run produces its segments one after another, so a run with open segments has at most one an island could produce now: "runs with open segments" bounds that, and "open segments" counts the rest of each run too. Replays are separate and can go out several at once, even from one run: a fraction of done segments is replayed, and the status does not say which, so "done, not verified" is an upper bound on replay work, not a count of it. "Live islands that last advertised all of these" comes from each island's most recent ask for work and is not a promise: work is still gated on each request, by what that request advertises.

Gardens

Each garden's public view (its newest 14 days). Keeper actions are commands to run in a shell with BL_ADMIN_TOKEN set (apps/coordinator/README.md, "Keeper (admin) endpoints"); this page never sends them. A failed or diverged day older than the days shown is found from the failures and divergences below. A day replayed by an island that reported the same device type as its producer may have been replayed on the same computer: it is "replayed here, not yet verified elsewhere".

Failures

Segments an island could not run as given (a scheduled feed the world refused); the run stops there. The way out is an upstream reject for an experiment, or the keeper's requeue for a garden day.

Divergences

Observation mismatches

The replay's observation files differ from the producer's; informational, the segment's status does not change.

Islands

Device type is the adapter description an island reported at join: a lower bound on computers, never an identity. Runner comes from the user agent the island reported (one starting "deno " counts as headless); nothing checks it. Capabilities are as each island last advertised them when it asked for work (the coordinator keeps the names it gates on and at most four others, the first in sorted order); work is still gated on each request, so a recorded capability never promises a task. After an upgrade, an island counts as "none recorded" until it next asks for work, even while it heartbeats on a long task.
